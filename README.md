## 👋 About This Repository

This repo is my **learning journal from the TekWorks training program** - a structured, industry-aligned program designed to transform students into job-ready data science professionals. Each folder represents an algorithm I studied, implemented in Python (Jupyter Notebooks), and documented with real datasets as part of the curriculum.

Over 84 commits. Countless hours of hands-on work. One goal: *build genuine, practical understanding of how machines learn.*

## 🚀 Getting Started

**Clone the repo:**
```bash
git clone https://github.com/akashgardas/Machine-Learning.git
cd Machine-Learning
```

**Install dependencies:**
```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

**Launch Jupyter:**
```bash
jupyter notebook
```

Navigate to any module folder and open the `.ipynb` file to explore.

## 💡 Approach

The TekWorks program emphasized real-world application over theory alone. Every notebook in this repo follows a pattern instilled through the training:

1. **Intuition** — what problem does this algorithm solve and why?
2. **Math** — the core equations, unpacked
3. **Implementation** — building it up in Python
4. **Evaluation** — measuring performance honestly
